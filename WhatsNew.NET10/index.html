01 — C# 14 Available Now

nameof with Unbound Generic Types

Unbound Generic nameof

Available

Use the nameof expression on unbound generic types without specifying type arguments. This returns the type name with arity, useful for generic type introspection, logging, and code generation scenarios.

Old Way 
// Required type arguments
var name = nameof(List<int>);
// Returns: "List"

// Or use Type.Name with arity
var typeName = typeof(List<>).Name;
// Returns: "List`1"
C# 14 
// nameof on unbound generics
var listName = nameof(List<>);
// Returns: "List`1"

var dictName = nameof(Dictionary<,>);
// Returns: "Dictionary`2"

var funcName = nameof(Func<,,>);
// Returns: "Func`3"

Upcoming C# 14 Features
