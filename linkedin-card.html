EF Core 10.0

New Parameterized Collection Translation

EF Core 10 introduces a smarter translation strategy for parameterized collections. Each value becomes a scalar parameter with automatic padding for better query plan reuse.

EF Core 8/9 
// JSON array translation
int[] ids = [1, 2, 3];

var blogs = context.Blogs
    .Where(b => ids
        .Contains(b.Id))
    .ToListAsync();

-- SQL: OPENJSON (complex)
WHERE [Id] IN (
  OPENJSON(@p0)
);
EF Core 10 
// Scalar parameters
int[] ids = [1, 2, 3];

var blogs = context.Blogs
    .Where(b => ids
        .Contains(b.Id))
    .ToListAsync();

-- SQL: Individual params
WHERE [Id] IN (
  @p1, @p2, @p3
);

-- 8 values? Pad to 10!
WHERE [Id] IN (
  @p1, ..., @p8,
  @p9, @p10
);
Benefits:
• Better query plan reuse (cache efficiency)
• Same SQL structure for different collection sizes
• Cardinality info preserved for query optimizer
• Configurable: Parameter, Constant, or JsonArray
